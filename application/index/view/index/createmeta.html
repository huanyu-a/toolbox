🧾Meta 标签生成 / 分析

可视化生成网页 Meta 标签代码，或粘贴已有 HTML 片段分析其 title / description / keywords 是否规范、给出优化建议。

📖 关于 Meta 标签

title 建议不超过 30 个汉字（约 60 字节），description 建议 50~160 字符，keywords 建议 3~8 个关键词。缺失或超长的 Meta 信息会影响搜索引擎收录与点击率。

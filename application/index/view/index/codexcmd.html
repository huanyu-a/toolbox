故障排查

① API 速率限制

根因：请求频率过高 · 解法：等待或升级 API 套餐
操作命令
查看限额codex quota
降低频率codex config set rate_limit 10

② 生成代码不完整

根因：max_tokens 设置过低 · 解法：增加 token 限制
操作命令
增加限制codex config set max_tokens 8192

③ 代码质量不佳

根因：提示词不够清晰 · 解法：提供更详细的上下文
操作命令
添加上下文codex generate --context "使用 TypeScript + Express"

④ 网络连接超时

根因：网络不稳定或防火墙拦截 · 解法：检查网络或配置代理
操作命令
测试连接curl https://api.openai.com
设置代理export HTTPS_PROXY=http://proxy:port

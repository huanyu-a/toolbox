故障排查

① 记忆保存失败

根因：记忆容量已满或格式错误 · 解法：清理旧记忆或检查格式
操作命令
检查容量pi memory stats
清理旧记忆pi memory prune --older-than 30d

② 对话响应慢

根因：上下文过长或模型负载高 · 解法：减少上下文或切换模型
操作命令
压缩上下文pi compress
切换模型pi config set model gpt-3.5-turbo

③ 个性化不生效

根因：配置未正确加载 · 解法：重启会话并验证配置
操作命令
验证配置pi persona validate
重启会话pi restart

④ API 连接失败

根因：网络问题或 API Key 失效 · 解法：检查网络并重新设置密钥
操作命令
测试连接pi ping
重置密钥pi config set api_key NEW_KEY

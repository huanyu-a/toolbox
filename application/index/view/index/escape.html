🔤Escape 加密/解密

Escape 在线编码解码工具：对字符串进行 Escape 加密或 Unescape 解密，字符码不超过 255 输出 %XX，其余输出 %uXXXX，与经典 escape() / unescape() 语义一致。

📖 关于 Escape 编码

Escape 编码是 JavaScript 早期的字符串转义方式：字符码不超过 255 的输出为 %XX（十六进制两位），其余输出为 %uXXXX（UTF-16 码元的四位十六进制），例如"中"转义为 %u4E2D。解密时按正则解析 %XX 与 %uXXXX 还原字符。本站转换完全在本地完成。

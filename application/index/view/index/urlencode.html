🔗URL 编码/解码

URL 编码解码工具，支持 UrlEncode 编码与 UrlDecode 解码，可将汉字与特殊字符转换为 %XX 形式的 URL 编码，也能一键还原为原文。

📖 关于 URL 编码

URL 中只允许使用 ASCII 字符，汉字、空格以及 # & ? 等特殊字符会被编码为 %XX（UTF-8 字节）形式，例如"中"编码为 %E4%B8%AD；解码则是逆过程，把 %XX 还原为原始字符。本站转换完全在本地完成。

📖 什么是 GUID

GUID（Globally Unique Identifier，全局唯一标识符）是一个 128 位（16 字节）二进制数，格式为 "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"，其中每个 x 是 0-9 或 a-f 的十六进制数字。GUID 重复的可能性极小，可用于所有需要唯一标识符的计算机与网络场景。本工具使用浏览器密码学级随机源（crypto.getRandomValues）生成。

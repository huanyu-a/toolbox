📖 关于 JSON 工具箱

JSON（JavaScript Object Notation）是一种轻量级数据交换格式，广泛用于前后端通信与配置文件。本页将原独立的 JSON 格式化/校验、压缩转义、JSON 转 GET 参数、JSON↔XML、JSON↔YAML、JSON↔CSV/Excel、JSON 生成 C#/Java 实体类、JSON 生成 Go 结构体等工具合并为一处，便于统一使用。转换过程全部在浏览器本地完成，不会上传任何数据。

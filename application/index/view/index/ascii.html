📖 关于 ASCII

ASCII（American Standard Code for Information Interchange）用 7 位二进制表示 128 个字符：0~31 为控制字符，32~126 为可打印字符（含数字、大小写字母与标点），127 为 DEL。扩展 ASCII（128~255）在不同编码中含义不同，本表按 Windows-1252 常用字符列出。

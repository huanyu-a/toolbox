📖 关于 HEX / RGB 转换

RGB 颜色由红、绿、蓝三个通道组成，每个通道取值 0~255；HEX 则是用两位十六进制数表示一个通道（如 #FF0000 = rgb(255,0,0)）。转换支持 #RRGGBB 与 #RGB 简写两种 HEX 格式，以及 255,255,255 或 rgb(255,255,255) 形式的 RGB 输入，结果实时显示并可复制。调色板支持系统取色器、色相滑块与常用色板，点击「应用到转换」或色板色块可联动到转换面板。

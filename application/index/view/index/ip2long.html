🌐IP 地址与数字地址互转

IPv4 地址与 32 位无符号整数互转，复制数字地址到浏览器访问与直接访问 IP 效果相同。

📖 转换说明

数字地址是 IP 地址的一种数字化表现形式。例如 66.102.7.147 的计算过程：66×256³ + 102×256² + 7×256 + 147 = 1113982867。在浏览器中访问 http://66.102.7.147 与 http://1113982867 是相同的效果。

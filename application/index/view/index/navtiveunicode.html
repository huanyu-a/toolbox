📖 关于 Native / Unicode 编码

Unicode 为每个字符分配唯一的码点（Code Point），常见表示形式有 \uXXXX（JavaScript 转义）、&#xHHHH;（十六进制 HTML 实体）、&#DDDDD;（十进制 HTML 实体）。例如"中"对应 \u4E2D、中、中。本站转换完全在本地完成。

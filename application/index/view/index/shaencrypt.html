🧮SHA 加密工具

支持 SHA1 / SHA256 / SHA512 三种不可逆哈希算法，内容仅在本机浏览器计算，绝不上传服务器。

📖 关于 SHA

SHA（Secure Hash Algorithm，安全散列算法）是比 MD5 更严格可靠的不可逆加密算法，被广泛应用于移动端接口数据签名、文件完整性校验等场景。本工具使用浏览器内置 Web Crypto API 实现 SHA-1、SHA-256、SHA-512 三种算法，结果与标准实现完全一致。
